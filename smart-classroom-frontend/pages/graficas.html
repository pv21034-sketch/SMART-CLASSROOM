Acerca de estas gráficas

Las gráficas presentan mediciones ambientales registradas en SMART CLASSROOM y consultadas mediante el backend Rust, desarrollado con Axum y SQLx.

La temperatura y la humedad relativa son las variables medidas directamente por el sensor DHT22. El punto de rocío, la humedad absoluta y la presión parcial del vapor de agua se estiman mediante ecuaciones termodinámicas, utilizando la aproximación de Magnus y el modelo del gas ideal.

La variación térmica se calcula utilizando la diferencia de temperatura y el tiempo transcurrido entre mediciones consecutivas de una misma jornada.

Los datos históricos se consultan desde PostgreSQL mediante Supabase. Las consultas no modifican ni eliminan los registros almacenados.
